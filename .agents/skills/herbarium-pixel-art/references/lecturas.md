# Referencias externas de consulta

Usarlas como estudio, no como licencia para importar arte, componentes o nuevas convenciones. Las reglas de Herbarium tienen prioridad.

- https://mektxt.com/ — referencia de identidad y tipografía indicada por el propietario.
- https://dos-age.com/ — referencia de interfaz pixel art indicada por el propietario. Examinar composición y uso de píxeles, no copiar recursos.
- https://lospec.com/articles/pixel-art-where-to-start/ — guía y selección de recursos para estudiar siluetas, clusters, color y animación.
- https://github.com/ProkStudio/skills/tree/main/skills/game/2d/pixel-art-fundamentals — skill de fundamentos; leer junto con referencias de densidad, bordes, sombreado y crítica cuando corresponda.
- https://github.com/MingfengHong/pixel-art-studio — skill y herramientas opcionales de raster, sprites, UI, animación y exportación. El repositorio indica licencia MIT para código/documentación y avisos separados de arte. Revisar scripts y licencias antes de instalar. Herramientas locales requieren Pillow; no incorporar dependencias al runtime ni usar sus assets como identidad del juego.

No se han incorporado archivos ni código de repositorios de terceros a este paquete. Las skills propias fueron escritas para Herbarium.
